# Visual direction

Proposed direction; not yet selected by João.

## Recommendation: a warm personal editorial site

The first screen pairs a clear introduction with a portrait. Below it, three featured stories show real work. A quieter about/now section adds interests and context. A simple contact invitation closes the page.

| Element | Proposed treatment |
| --- | --- |
| Background | Warm cream, #F7F5EF |
| Main text | Charcoal, #202823 |
| Accent and links | Deep green, #24533F |
| Supporting color | Muted stone, #DFE3D9, for surfaces rather than body text |
| Headings | Expressive editorial serif; test Georgia as a simple starting point |
| Body | Clean sans-serif; readable system font stack |
| Layout | About 1120px maximum width; narrower long-form text; generous vertical spacing |
| Photography | Supplied natural-light portrait if confirmed; retain a natural appearance |
| Interaction | Clear underlined links, restrained hover feedback, visible keyboard focus |

Colors are starting tokens; verify contrast in actual components.

## Structure sketch

```text
João Ferrari                     Work / About / Contact

I'm João Ferrari.                [Portrait]
[One clear statement]
[Current focus]
Explore my work / Get in touch

Selected work
01 Vocanize                      [Real screenshot + story]
02 Research                      [Question + current output]
03 Community / leadership        [Event image + contribution]

About João / What I'm focused on now
[Brief personal story and dated update]

Let's connect                    [Confirmed public links]
Source and build story           [Public GitHub repository]
```

On phones, stack the portrait and text, retain readable spacing, and keep navigation simple.

## Reference shortlist

Reviewed October 28, 2026. These references inform structure and content; their exact visual styling has not been audited here.

- [Lee Robinson](https://leerob.com/): concise personal introduction and a direct path into writing. Borrow the clarity of the opening.
- [Brian Lovin](https://brianlovin.com/): a personal home connecting writing and varied projects. Borrow the way different interests remain part of one identity.
- [Patrick Collison](https://patrickcollison.com/): a simple index into interests and ideas. Borrow the permission to include curiosity alongside professional work.

João should provide two or three references he likes and identify the specific parts: typography, spacing, colors, motion, photography, or navigation. Avoid copying a reference wholesale.

## Alternatives to compare

- **Minimal technical:** white/black, sans-serif typography, compact project lists, emphasis on code and build notes.
- **Expressive personal:** stronger color, more photography, playful details, emphasis on personality and varied interests.
